# KeySuite V4.23.14 Upgrade

Upgrade from V4.23.13.

## Changes

- BFI Assembly now follows the CHC System route directly.
- Default System BOM: BFI pump x2, KeyPLC panel x1, manifold x1, GWS tank x1.
- Default operating arrangement: 1 Duty + 1 On Demand.
- BFI motor kW, threaded connection DN equivalents, series and shut-off head are carried into automatic System sizing.
- No database migration is required.
- No Telegram function redeployment is required.
