# KeySuite V4.29.05 Upgrade

## Change

On macOS, CHC C4/C6 Product PDF now opens the same visible report-tab flow used by Selection before the print/save dialog appears. The hidden desktop print frame is no longer used. Selection also performs two additional late Safari fit checks so the embedded C4/C6 curve consistently returns to its full-width zoomed-out view.

## Locked scope

- CHC C4/C6 PDF content, values, page layout, branding and filenames remain unchanged.
- Existing V4.29.04 PDF preparation caches and V4.29.03 HP/kW formatting remain unchanged.
- No hydraulic or motor calculations, selector data, pricing, actions, or other product families are changed.
- No database migration or edge-function deployment is required.
