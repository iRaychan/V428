# KeyHQ V0.1 Master Building Upgrade

Baseline: **KeySuite V4.29.22 Full**  
Module release: **KeyHQ V0.1 Master Building**  
Cache identifier: **keyhq01**

Copy every path listed in `UPGRADE_FILE_MANIFEST_KEYHQ_V0.1.txt` over an existing complete KeySuite V4.29.22 installation, preserving folders. Clear the browser/site cache or reload twice after deployment.

This upgrade changes the KeyHQ presentation shell only. It does not add, remove, or edit Supabase migrations, database objects, authentication behavior, RLS policies, Edge Functions, product selection, pricing, quotations, or other KeySuite modules.

The V0.1 shell provides eight aligned levels, a taller shared Levels 1–2 podium, vertically continuous lift/stair cores, floor navigation, sunset/night previews, and a 50/50 rooftop split. Detailed interior design and additional live integrations are intentionally deferred.
