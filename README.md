# KeySuite V4.28.75 Upgrade

Upgrade V4.28.74 by copying this package over the current installation.

V4.28.75 fixes only the delayed initial CHC curve rendering from Dashboard Quick Selection. The Quick Selection handoff now accepts the readiness flag published by the unified selector first-open module, avoiding the previous 4.5-second fallback wait while retaining legacy compatibility.

No curve data, calculations, pricing, layouts, frozen PDF files, database migrations, or edge functions are changed.

Deployment is not included in this build.
