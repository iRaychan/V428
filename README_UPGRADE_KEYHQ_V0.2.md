# KeyHQ V0.2 Living Headquarters Upgrade

Baseline: **KeySuite V4.29.22 Full**  
Module release: **KeyHQ V0.2 Living Headquarters**  
Cache identifier: **keyhq02**

Copy every path listed in `UPGRADE_FILE_MANIFEST_KEYHQ_V0.2.txt` over an existing complete KeySuite V4.29.22 installation, preserving folders. Clear the browser/site cache or reload twice after deployment.

This upgrade changes the KeyHQ presentation layer and its regression coverage only. It does not alter Supabase migrations, database objects, authentication, RLS, Edge Functions, product selection, pricing, quotations, permissions or other KeySuite modules.

## Visual scope

- Replaces the repetitive glass stack with articulated podium, stepped office volumes, a continuous vertical core/spine and planted terraces.
- Keeps the aligned lift/stair core and the taller shared Levels 1–2 podium.
- Uses the original `keylargo-logo.png` directly, without pixel recoloring.
- Improves landscape, arrival walk, water/green edges, façade materials, lighting and rooftop pergola/solar canopy.
- Rebuilds Level 5 as a KeyBot Telegram AI operations center with seven triple-monitor workstations, operations wall, equipment rack, storage and refined human avatar rendering.
- Preserves truthful feed states: live, connected-empty, demo, locked and unavailable remain visibly distinct; no demonstration event is presented as live.

## Deployment

No database migration or Edge Function deployment is required for this visual-only upgrade.
