# KeySuite V4.28.61 Upgrade

Upgrade from V4.28.60 by replacing the files in this package.

## Changes

- Selection > CR now appears under B.G.Reich beside CHC C4, CHC C6, BFI and ES instead of as a separate top-level item.
- CR uses the same outer Selection layout and configuration workflow as CHC: Material, Mechanical Seal, Elastomer, Connection and Supply.
- CR navigation establishes CR presentation context, so selected and alternative model labels remain CR instead of inheriting CHC labels.
- CR selection continues to use the independent CR engineering data and selector core for model ranking and hydraulic curves.
- The CR selector is constrained to the KeySuite content width so actions, results and curves are not clipped and no extra horizontal scrollbar is introduced.
- The CR action row is standardized to PDF, Assembly and Quote.
- Frozen PDF and quotation print layouts are unchanged.

No new V4.28.61 database migration is required.
