# KeySuite V4.23.16 Upgrade

Upgrade from V4.23.15.

## Changes

- Standardises the shared System manifold/accessory description globally, including CHC and BFI.
- Both suction + discharge flexible: `Gate valves and flexible joints on the suction and discharge ports of each pump`.
- Suction flexible only: `Flexible joint on the suction port of each pump`.
- Strainer only: `Strainer on the suction port of each pump`.
- Suction flexible + strainer: `Flexible joint and strainer on the suction port of each pump`.
- Discharge flexible: `Check valve and flexible joint on the discharge port of each pump`.
- No discharge flexible: `Check valve on the discharge port of each pump`.
- Pressure gauge: `1 pressure gauge on the discharge manifold`.
- No database migration is required.
- No Telegram/KeyBot function redeployment is required.
