# KeySuite V4.23.20 Upgrade

Apply over V4.23.19.

## Changes
1. User Settings now contains `Optimize PDF file size`. It defaults OFF.
2. Removed Optimized PDF controls from Product, Selector and Quotation Export toolbars; PDF / Assembly / Quote returns to the previous arrangement.
3. Quotation History is sorted newest-first immediately before rendering, including after filters/search/refresh.

No Supabase database migration or Telegram/KeyBot function redeploy is required.
