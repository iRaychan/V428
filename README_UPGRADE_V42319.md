# KeySuite V4.23.19 Upgrade

## Product / Selector PDF control visibility
- Shows **Optimized PDF** directly beside the blue PDF button for CHC C4, CHC C6, BFI and ES selector/product views.
- Product Curve action bar wraps safely instead of clipping the optimization control on narrower layouts.
- Existing V4.23.18 PDF optimization ON/OFF preference is preserved.

## Quotation History
- Default order is now newest quotation first.
- Creation timestamp is primary; update timestamp and quotation number provide deterministic tie-breaking.

No database migration or Telegram / KeyBot function deployment is required.
