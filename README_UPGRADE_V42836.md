# KeySuite V4.28.36 Upgrade

This release makes the B.G.Reich ES and BFI Selection curve screens follow the contained Product curve layout. The Selection controls, main curve and right-side chart stack no longer expand beyond the embedded Safari viewport.

Upload all contents of the V4.28.36 Upgrade package over V4.28.35, preserving the folder paths. For an earlier installation, use the Full package. Back up the installation first and preserve your deployment-specific `config.js`. No database migration is required.

After deployment, reload the application and confirm V4.28.36. Check Selection → B.G.Reich → ES and BFI at desktop and narrow widths; the full top option row and right-side charts should remain visible without horizontal clipping.
