# KeySuite V4.28.60 Upgrade

Upgrade from V4.28.59 by replacing the files in this package.

## Changes

- CHC and CR Mechanical Seal Add-On inputs remain editable, use up to 288px each, and shrink within the card without forcing horizontal overflow.
- Product > Keylargo > ES Baseplate shows Assembly and Add to Quote on one row, with the helper text below.
- ES Baseplate `2\" × 4\"` maps to frame `100`; the frame is retained in Assembly/BOM configuration unless the Assembly frame is manually changed.
- Product CR and CHC curve frames are isolated and reset on page navigation.
- B.G.Reich CR is available under Selection with the existing independent CR hydraulic selector and Assembly/Quote routing.
- Quotation History has live partial, case-insensitive search across project, customer, quotation number, and available model/product values.
- Frozen PDF and quotation print layouts are unchanged.

No new V4.28.60 database migration is required.
