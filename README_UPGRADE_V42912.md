# KeySuite V4.29.12 Upgrade

## Changes

- Adds `CR` as an independent B.G.Reich row under Key → Customer → Brand / Series Price Preference.
- A Price-authorized CR row can be enabled under Customer Curve / Quick Selection preference.
- Assigned CR can appear in Dashboard Quick Selection.
- All V4.29.11 KeyBot access, scoped search and five-point curve behavior remains unchanged.

## Deployment

Upload the V4.29.12 application files to GitHub.

No Supabase database migration or Edge Function redeployment is required.
